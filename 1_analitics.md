## Описание корпуса

Для экспериментов использован корпус из 44 архивных документов, обработанных единым пайплайном. Внутри каждого документа страницы нарезаны, предобработаны, автоматически классифицированы по типу содержимого и распознаны средствами OCR [results_all_pages_merged.csv]. В сумме корпус содержит 2031 страницу.

### Типы страниц

По полю `page_type` выделяются четыре основных типа страниц:

- `dense_text` — 889 страниц (43.77%)
- `figure_or_table` — 792 страниц (39.00%)
- `mixed` — 274 страницы (13.49%)
- `image_or_blank` — 76 страниц (3.74%)

Таким образом, примерно половина корпуса — чисто текстовые страницы, а почти столь же большая часть — страницы с таблицами, схемами и другими визуальными материалами. Оставшиеся типы отражают смешанные макеты и низкотекстовые листы.

## Классы документов

На уровне документов типы страниц агрегированы в четыре класса:

- `textual` — 16 документов (552 страниц)
- `mixed_layout` — 5 документов (334 страницы)
- `visual_low_text` — 2 документа (68 страниц)
- `hybrid_other` — 21 документ (1077 страниц)

Класс `textual` образует ядро корпуса для лингвистического анализа: большинство страниц в этих документах относятся к типу `dense_text`, а доля `image_or_blank` минимальна.

Класс `mixed_layout` объединяет документы, где значимая доля страниц имеет тип `mixed` (текст + фигуры/таблицы). Это отчёты со сложным макетом, особенно интересные для задач разметки структуры страницы.

Класс `visual_low_text` представляет документы, в которых преобладают низкотекстовые страницы, например титульные листы и штампы. Для них OCR даёт мало содержательного текста, но они являются важным материалом для анализа визуальной структуры.

Класс `hybrid_other` описывает промежуточные случаи, где доли текстовых и визуальных страниц находятся в средних значениях.

## Качество OCR по классам документов

В среднем по всему корпусу OCR извлекает 835.27 символов на страницу, медиана составляет 399 символов. При этом 446 страниц имеют менее 50 распознанных символов, то есть OCR практически не даёт полезного текста для примерно пятой части корпуса.

По классам документов:

- `textual`: среднее число символов OCR ≈ 859, средняя плотность текста (`text_density`) ≈ 0.228, медиана ≈ 0.181.
- `mixed_layout`: среднее число символов OCR ≈ 1149, средняя плотность текста ≈ 0.128, медиана ≈ 0.111.
- `hybrid_other`: среднее число символов OCR ≈ 749, средняя плотность текста ≈ 0.141.
- `visual_low_text`: среднее число символов OCR ≈ 463, средняя плотность текста ≈ 0.052.

Таким образом, для задач, завязанных на текст, в первую очередь целесообразно использовать классы `textual` и `mixed_layout`, а документы класса `visual_low_text` преимущественно интересны с точки зрения визуального оформления.

## OCR по типам страниц

По типам страниц (в пределах всего корпуса):

- `dense_text`: среднее число символов OCR ≈ 1094.88, средняя плотность текста ≈ 0.258, медиана ≈ 0.201.
- `mixed`: среднее число символов OCR ≈ 1361.95, средняя плотность текста ≈ 0.103.
- `figure_or_table`: среднее число символов OCR ≈ 413.80, средняя плотность текста ≈ 0.082.
- `image_or_blank`: среднее число символов OCR ≈ 291.95, средняя плотность текста ≈ 0.019.

Страницы типа `dense_text` и часть `mixed` дают основной объём текста. Тип `figure_or_table` и особенно `image_or_blank` обеспечивают небольшой текстовый выход, но важны для структурного и визуального анализа.

## Layout‑типология документов

Для каждого документа рассчитаны доли страниц каждого типа: `dense_text_share`, `figure_or_table_share`, `mixed_share`, `image_or_blank_share` [results_document_layout_map.csv].

Наблюдения:

- У ряда документов гибридного класса доля `figure_or_table` превышает 0.6, то есть большинство страниц представлены таблицами и схемами.
- Текстовые отчёты имеют высокую долю `dense_text` (до 0.96) и низкую долю визуальных страниц.
- Документы класса `mixed_layout` демонстрируют одновременно заметную долю `mixed` и значимую долю `figure_or_table`, что подтверждает сложный макет.

В результате корпус можно рассматривать как структурно организованное множество документов, разделённых по преобладающему типу содержимого и пригодных как для классического OCR и лингвистического анализа, так и для задач компьютерного зрения и разметки макета страниц.
